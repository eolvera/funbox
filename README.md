### AML Transaction Risk Analysis
- **Files**:
  - `aml_trans_analysis.html`: D3.js visualization of high-risk cryptocurrency transactions by merchant, with tooltips showing average transaction amounts.
  - `aml_transaction_analysis.sql`: SQL script to query a simulated transaction dataset, flagging high-risk transactions for AML compliance.
- **Description**: This project analyzes cryptocurrency transactions to identify AML risks, using SQL to flag high-value or suspicious patterns and D3.js to visualize risk distribution. It supports compliance teams in regulatory reporting, aligning with KYC/CIP and sanctions requirements.
- **Relevance**: Reflects my ability to monitor compliance risks (e.g., reduced chargebacks by 15% in 2025) and simplify complex data for stakeholders

## How to Run

1. **Landing Page**:
   - Open `index.html` in a browser to view my portfolio and access the AML project via the Navbar.
2. **AML Visualization**:
   - Open `aml_trans_analysis.html` in a browser to view the interactive bar chart.
   - Hover over bars to see average transaction amounts.
3. **SQL**:
   - Execute `aml_transaction_analysis.sql` in a SQL environment (e.g., PostgreSQL, BigQuery) to query high-risk transactions and aggregate risk metrics.

## Setup

- **Repository**: Hosted on GitHub Pages (enable in repository settings, set `index.html` as the source).
- **Files**:
  - `index.html`: Portfolio landing page with a link to the AML project.
  - `aml_trans_analysis.html`: D3.js visualization of AML risk data.
  - `aml_transaction_analysis.sql`: SQL script for transaction analysis (from previous project, included in repository).
- **Dependencies**: D3.js v7 (loaded via CDN in `aml_trans_analysis.html`).
